How to run the session

Give the learner the five tasks without explaining the interface first. Help only when they are blocked, and record that help. Ask opinion questions after the tasks so comments do not replace observed behavior.

  1. Open Bookmoth and load the built-in sample or permitted material.
  2. Start a timer and give the tasks in order.
  3. Record each task as completed, completed with help, or blocked.
  4. Ask what felt clear, where they hesitated, and which output they would reuse.
  5. Export the record and store it inside the private Hive validation folder.

Evidence rule: five sessions are directional usability evidence. They do not prove learning gains, demand, or willingness to pay.
