# Contributing to Bookmoth

Bookmoth welcomes focused issues and pull requests.

1. Describe the learning problem before proposing a feature.
2. Preserve source IDs and uncertainty labels in every generated output.
3. Do not add features that answer active or proctored assessments.
4. Keep body text readable, controls keyboard accessible, and mobile layouts free of horizontal overflow.
5. Add a meaningful test when changing parsing, validation, exports, or the learning-pack schema.
6. Run `npm run check` before opening a pull request.

Brand art must be original or have documented commercial-use permission. Do not submit copied characters, logos, or social-media artwork.
